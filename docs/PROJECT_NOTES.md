# 메드스카이 정시 합격 분석 도구 — 진행 상황 분석 (인수인계 메모)

## 1. 파일 구성 (업로드된 2개, 저장소에는 아직 미포함)
| 파일 | 크기 | 정체 |
|---|---|---|
| 정시 분석 도구 (`5913a023-…html`) | 8.8MB, 단일 HTML | **작업 중인 정시 프로그램** |
| 수시 컨설팅 도구 (`b8e60eca-…88.html`) | 18MB, 단일 HTML | **레퍼런스** (지난 수시 원서 컨설팅용) |

## 2. 정시 도구 구조
- 헤더(자산 보호 문구 + 대학·학과 검색) / 탭 5개: 학생 정보 · 대학 둘러보기 · 정밀 매칭 도구 · 지원희망 모집단위(가·나·다군 보드) · 데이터 관리
- **핵심 아이디어**: 엑셀 `고속성장분석기`(.xlsb)의 수식을 JS로 재현하는 자체 엑셀 수식 엔진(XLEngine) 내장.
  - 현재 내장 모델: `20260902 고속성장분석기 실채점판 (date:20260928)`, 수식 모양 222가지, 압축 전 31.8MB JSON을 gzip+base64로 `<script id="model">`에 내장.
  - 시트: 수능입력, 내신입력, 전체/이과/문과기준분석결과(각 6,240행×57열, 모집단위별), COMPUTE, RESTRICT, SUBJECT1~3, PERCENTAGE
  - 지원 함수: IF/IFERROR/AND/OR/VLOOKUP/HLOOKUP/MATCH/INDEX/OFFSET/COUNTIFS/ROUND 등 (미지원 함수는 데이터 관리 화면에서 경고)
  - 학생 성적 입력 → `수능입력` 시트 셀 주입 → 결과 시트의 판정(적정/예상/소신/위험/결격)·학생 누백·순위 재계산 (약 0.x~수 초)
- 데이터 관리: 새 고속성장분석기 파일 업로드 → 파싱 → 엑셀 캐시값과 자동 대조 검증 → 적용(관리자는 assets/db에 저장해 전원 반영)
- 모집단위 리스트: 대학·학과·군·정원·지역·계열·구분(의치한약수·교대·과기원·일반·전문), 과거 합격권 누백(25→21), 적정/예상/소신 컷, 국·수·탐 반영비, 영어 감점표
- 부가 기능: 펑크 예측(입결 급등/급락·소수모집 기반 규칙), 열별 필터·정렬, 모집단위 리포트 드로어(이미지 저장), 컨설턴트 코멘트, 학생 프로필 저장/내보내기/가져오기, 다크모드
- 기술 의존: cdnjs(xlsx, pako, html2canvas), Claude 아티팩트 런타임(`window.claude.use('db'|'user'|'downloads'|'assets')`)

## 3. 수시 레퍼런스 구조
- 탭: 학생 정보 · 대학 둘러보기 · 정밀 매칭 도구 · 지원희망 모집단위 · **생기부 진단** · **산출된 보고서 열람**
- 데이터: `raw-data`(27,492행 × 49열: 대학/학과/전형/22~26 입결/경쟁률/충원/최저/반영방법…), 평가요소(`eval-data`), 로고·가이드 이미지
- 기능: 학기별 성적, 생기부 PDF 추출(pdf.js)→AI 진단, 보고서 섹션(2-1, 2-2, 학년별, 3 전략, 상담 분석) 생성, 인쇄/이미지 출력, 최저 충족 판정, 펑크 예측, 프로필은 localStorage
- 생기부 진단/보고서는 `localhost:3001` 별도 서버(`/api/generate-*`)를 호출하는 구조

## 4. 정시 도구에서 남은 이슈/이관 시 고려사항
1. 클로드 아티팩트 전용 API(db/user/downloads/assets)에 의존 → 외부 호스팅 시 대체 저장소(Supabase 등)·다운로드 처리 필요
2. 단일 파일 8.8MB(모델 31.8MB 내장) → 데이터/코드 분리, 로딩 최적화 여지
3. 수시 도구에 있는 기능 중 정시에 아직 없는 것: 학기별 성적/생기부 진단, 최저(수능) 충족 판정 개념은 다름, 상담 분석, 인쇄형 종합 보고서
4. 데이터 갱신 절차(고속성장분석기 업로드)는 구현됨 — 운영 방식(누가 업로드/권한) 정리 필요
