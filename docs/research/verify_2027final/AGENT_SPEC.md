# 조사원 작업 지침 (2027 요강 기준 학생부 반영 재조사)

대입 정시 모집요강 원문에서 **학생부(생활기록부) 반영 방법**을 앱의 모집단위별로 확정해 JSON으로 저장한다.

## 입력
- 요강 텍스트(`<txt>`, pdftotext 결과. 쪽은 form-feed(\f)로 구분, PDF 쪽 번호는 1부터)
- 쪽 번호 검색 도구: `python3 -I /workspace/medsky_study/tools/guide_grep.py <txt> grep <정규식> [앞뒤줄수]`, `... page <시작쪽> [끝쪽]`, `... pages`
  - 요강 전체를 한꺼번에 읽지 말고 grep으로 위치를 찾아 필요한 쪽만 읽는다. 키워드: 학교생활기록부, 학생부, 교과, 출결, 서류, 정성, 면접, 실기, 전형요소, 반영비율, 학교폭력, 수시.{0,6}이월, 모집단위
- 앱 모집단위 목록(`<units>`): [{학과, 구분, 군, 정원, 현재(앱의 현재 분류), 현재사유}]. **전부** 분류한다(이미 분류된 것도 요강으로 다시 확인)

## 분류 기준 (class)
- 미반영: 수능(·실기)만 반영하고 학생부 점수·평가를 쓰지 않음. 학교폭력 조치 감점/부적격만 있어도 미반영
- 정량: 학생부(교과 등)를 점수로 환산해 총점에 반영하거나 출결 등을 점수화해 반영
- 정성: 학생부(서류)를 평가자가 정성적으로 평가해 반영(서류평가 포함)
- 미확인: 요강에서 해당 단위를 같은 이름으로 확인하지 못했거나 근거가 모호함(추측 금지, reason에 이유)
- 면접·실기·교직적성 등 수능·학생부 외 요소는 class에 넣지 말고 group의 `interview`/`note`에 쓴다
- 앱 단위가 수시이월이면 요강의 이월 선발 방식 규정을 확인해 따른다(규정이 없으면 미확인). [지역]·농어촌 등 특별전형 단위도 요강에서 정시 선발 방식을 확인한다
- 이름이 바뀐 것으로 추정되는 단위는 근거가 명시적이면(요강에 개명 표기) 매핑하고, 추정뿐이면 '미확인'으로 둔다

## 쓰는 방식 (앱 화면에 그대로 나온다)
- `summary`·`note`·`details`는 앱 문체인 **~해요체**로 쓴다. 예) "수능 100%로 선발해요. 학생부 점수는 반영하지 않아요."
- 앱 모집단위에 없는 전형(예: 학업성적우수자, 성인학습자, 재직자, 특성화고 이월 등 학생부 반영 전형)은 group에 넣지 말고 최상위 `otherTracksNotInApp`(문자열 배열)에만 적는다. 화면에 나가는 글에는 "앱에 없다"는 말을 쓰지 않는다
- 정원·모집군이 앱과 다른 것은 반영하지 않는다. 최상위 `rosterNotes`에 [{학과, 앱, 요강}]로 기록만 한다

## 출력 (JSON 배열 1원소 = 앱 대학 1곳; 캠퍼스가 둘이면 원소 둘)
```
[{"appUniv": "<앱 대학명 그대로>",
  "groups": [{"name": "전형 구분 이름", "class": "미반영|정량|정성",
              "summary": "한두 문장(해요체)", "details": ["핵심 규칙 ≤6개"], "note": "특이사항(학폭 감점 등)", "interview": "면접·실기 요약(없으면 빈 문자열)",
              "evidence": [{"quote": "요강에서 그대로 복사한 문장·표 행", "where": "PDF p.N"}]}],
  "unit_map": [{"학과": "...", "군": "...", "구분": "<units의 구분 그대로>", "group_idx": 0 또는 "미확인", "reason": "한 줄 근거(쪽 번호 포함)"}],
  "sources": [{"title": "<대학> 2027학년도 정시모집요강", "url": "<name_map의 파일 링크>", "kind": "대학 발행 요강 원문(경기도교육청 검색기 수록본)"}],
  "rosterNotes": [...], "otherTracksNotInApp": [...]}]
```
- unit_map은 `<units>`의 모든 단위를 한 번씩 포함해야 한다(학과+군+구분 그대로). 단위가 많으면 파이썬 스크립트로 이름 목록→group_idx를 지정해 만든다
- evidence 인용은 요강 텍스트에서 그대로 복사한다(표는 핵심 행). 쪽 번호는 'PDF p.N'
- 저장 후 `python3 -I /workspace/medsky_study/tools/final_check.py <결과.json> <units.json> <txt>`를 실행해 오류가 없게 고친다
- 보조 스크립트·임시 파일은 다른 조사원과 충돌하지 않게 반드시 파일명에 대학 이름을 넣어 `<scratchpad>/work/<대학이름>_*.py`처럼 만든다(공용 이름 mk.py 등 금지, 다른 작업의 파일을 수정·덮어쓰기 금지)
- 보고는 300자 이내(그룹 수, 분류 분포, 미확인 단위, 막힌 점)
