# 2027 정시모집요강 기준 학생부 반영 재조사 현황 (2026-10-28 마무리)

경기도교육청 정시모집요강 검색기의 대학 발행 요강(8~9월 공개본)을 원문으로 읽고 앱의 학생부 반영 분류(미반영·정량·정성·미확인)를 다시 확정했다. 조사원이 요강에서 근거를 뽑고 → 독립 검증자가 원문과 다시 대조하고 → 틀린 곳을 고쳐 앱(HB_DATA)에 반영하는 2단계 방식이다. 정원·모집군은 반영하지 않고 `rosterNotes`에 기록만 했다. 앱에 없는 전형은 화면에 표시하지 않고 `otherTracksNotInApp`에만 기록했다.

## 결과 (앱 v50 기준)
- 재조사 완료 대학: **154곳** (결과 파일 `final_<대학>.json`, 시범 4곳은 `pilot_*.json`)
- 앱 전체 모집단위 6,234개 분류: 미반영 4,130 · 정량 398 · 정성 142 · 미확인 1,564
- 재조사 완료 대학 안의 '미확인' 560개: 요강에 같은 이름이 없거나 개명 표기가 없거나 이월 규정이 없는 단위(추측하지 않음) → `docs/research/unconfirmed_units_2027.csv`
