# 독립 검증자 지침

다른 조사원이 만든 '정시 모집요강 학생부 반영 분류' 결과를 요강 원문과 대조해 오류를 찾는다. 조사원의 결론을 믿지 말고 원문으로 직접 확인하고, 의심스러우면 반박한다. 결과 파일은 수정하지 않는다.

분류 기준: 미반영=수능(·실기)만 반영(학폭 감점/부적격만 있어도 미반영) / 정량=학생부를 점수로 환산·출결 점수화 / 정성=학생부 서류의 정성평가 / 미확인=근거 없음.
도구: `python3 -I /workspace/medsky_study/tools/guide_grep.py <txt> grep <정규식> [앞뒤줄수]`, `... page <시작쪽> [끝쪽]`.

## 검증 항목
1. group.class·summary가 원문 해당 쪽과 일치하는지(인용이 표를 합쳐 쓴 것이라 글자가 완전히 같지 않을 수 있으나 내용이 원문에 없거나 틀리면 오류).
2. **누락 탐색**: 요강 전체에서 '학교생활기록부, 학생부, 교과, 출결, 서류, 정성, 면접, 실기, 가산점, 감점'을 grep해, 정시 수능 전형에서 학생부가 점수·평가로 쓰이는 곳이 결과에서 빠졌는지 확인(특별전형·수시이월·특정 학과 포함). 앱 모집단위(units)에 해당하지 않는 전형(성인학습자·재직자·실기 전형 등)이 빠진 것은 오류가 아니다.
3. unit_map: 파일의 units 중 (a) 결과가 현재 분류와 다르게 본 단위 전부 (b) 미확인 단위 전부 (c) 나머지에서 무작위 15개를, 학과 이름·군·[지역]·수시이월 표기를 요강과 대조해 올바른 그룹으로 들어갔는지, 미확인이 정말 요강에 없는지, 개명 매핑이 요강에 명시돼 있는지(추정이면 미확인이어야 함) 확인.
4. 결과의 summary/note가 사실과 다른 내용(숫자·비율·전형명)을 담고 있는지.

## 보고 (400~700자)
판정(통과/수정 필요), 틀린 곳(단위·쪽·정답), 누락, 근거가 약한 매핑, 전체 신뢰 의견.
