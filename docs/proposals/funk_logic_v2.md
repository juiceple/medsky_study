# 펑크 예측 로직 보완 제안 (제안서 — 프로그램에는 아직 반영하지 않음)

작성: 2026-11-18. 근거: 집필 중인 정시 컨설팅 도서 5개 챕터(입결 변동 패턴 분석 · 진학사 분석의 기술 · 경쟁률과 입결의 관계 · 셀프 컨설팅의 메커니즘)와 현재 앱 v50의 `funkOf()` 로직·데이터.

## 0. 한 줄 요약
현재 로직은 책의 첫 번째 규칙("입결이 오르면 다음 해엔 내려간다")만 단순화해 담고 있고, ① 대학 전체의 흐름을 빼지 않아 후보가 너무 많이 나오고(23.6%), ② 70% 컷 간극 점검이 조건이 거꾸로라 한 번도 작동하지 않으며, ③ 학생의 위치(안정 카드인지 상향 카드인지)에 따라 같은 신호의 의미가 달라진다는 책의 핵심을 반영하지 못합니다. 앱에 이미 있는 자료만으로 1차 보완이 가능하고, 경쟁률·진학사 값은 입력 기능을 붙이면 2·3차로 확장할 수 있습니다.

## 1. 지금 앱이 하는 일 (v50, `funkOf(i)`)
사용하는 자료(모집단위마다): 합격권 누백 5개년 `h[0..4]`(분석기 열 2511·2411·2311·2211·2111), 상위 70% 누백 5개년 `h70[0..4]`, 정원, 군.

```
last = h[0]                      // 가장 최근 해(분석기 2511)
prev = h[1..3] 중 있는 값        // 직전 3개년 (h[4]=2111은 안 씀)
avg  = prev의 산술평균
r    = last / avg
 r < 0.6   → score +2  "입결 급등, 다음 해 지원자가 피하는 경향"
 r < 0.78  → score +1  "직전 3년 평균보다 올랐다"
 r > 1.6   → rebound   "크게 내려갔다, 올해 지원이 몰릴 수 있다"
 r > 1.3   → rebound   "평균보다 낮아 올해 반등할 수 있다"
정원 1~5명: score>0이면 +1, 아니면 메모만
수시이월: 메모('이월 인원 확정 전')
h70[0] > last × 1.6 : 메모('합격권과 70% 누백 차이가 커서 추합 폭이 넓었다')
결과: score≥3 '강한 펑크 후보' / ≥1 '펑크 후보' / rebound '반등 주의' / 그 외 '평이'
```
(누백은 작을수록 상위권이라 r가 작으면 "입결이 올랐다"는 뜻입니다.)

## 4. 제안 로직 (1차: 지금 있는 자료만으로)
표기: `L_t = ln(누백_t)`. t=0 최근 해(2511), t=1 2411, … t=4 2111. 누백은 작을수록 상위권이므로 **ΔL이 음수 = 입결 상승**.

### 4-1. 대학 흐름을 뺀 상대 변화 R (책 ①②⑥)
```
Δ   = L_0 − mean(L_1..L_3)            // 최근 해 vs 직전 3개년 (최소 2개년 필요)
peer = 같은 대학 + 같은 계열(인문/자연)의 다른 모집단위들 (5개 이상일 때)
       그보다 적으면 전체 일반대 중앙값
R   = Δ − median(peer의 Δ)            // 대학·계열 흐름 대비 이 학과의 이탈
```
해석: **R ≤ −0.30** 매우 높아짐(입결 급등, 올해 하락 압력 +2), **−0.30 < R ≤ −0.20** 높아짐(+1). **R ≥ +0.30** 매우 낮아짐(올해 반등 압력 +2), **0.20 ≤ R < 0.30**(+1). 이 범위에서 후보 비율은 R≤−0.2 약 6.4%(238/3,750), R≤−0.3 약 2.7%.
3개년 창은 같은 식을 `mean(L_1..L_3)` 대신 `L_1`(직전 한 해)과 비교해 보조로 표시(책의 "5개년으로 추리고 3개년으로 다시 비교").

### 4-2. 70% 컷 간극 교정 (책 ③)
```
G_t = ln(합격권누백_t / 70%컷누백_t)  (≥0)   // 마지막 합격자가 70%컷보다 얼마나 뒤쳐졌나(충원 깊이)
G_t ≥ ln 1.35 (상위 약 3%)  → '충원이 깊게 돌았다'
G_t ≥ ln 1.20 (상위 약 10%) → '충원이 다소 깊다'
```
- 간극이 크면서 그 해 입결이 낮아졌으면(그 해 R_t ≥ +0.2) → **'과거 펑크 이벤트' 확정**(책의 순수 펑크 2조건: ① 입결이 혼자 튐 ② 70% 컷과 최종컷 간극이 큼). 둘 중 하나면 '약한 신호'.
- 주의: 이 앱 자료로 검증해 보니 **간극 단독 예측력은 약했습니다**(R이 평범한 학과만 보면 간극이 커도 다음 해 변화가 −0.03로 차이 없음). 그래서 간극은 점수에 크게 넣지 않고 이벤트 확인과 근거 표시에 씁니다.

### 4-3. 과거 펑크 이벤트와 변동성 (책 ④⑤)
```
이벤트(t) = ( R_t ≥ +0.20 )  AND  ( G_t ≥ ln1.20  또는  G_t가 그 학과 평균보다 0.10↑ )   // t=0,1,2에서 판정(직전 ≥2개년 필요)
이벤트 횟수 E, 마지막 이벤트 연도 t*
변동성 vol = 추세를 뺀 로그 누백의 표준편차(4개년 이상)    // 분포: 30%=0.077, 70%=0.151, 90%=0.262
등급: 불안(vol≥0.15 또는 E≥2), 보통, 안정(E=0 이고 vol<0.08)
```
- t*=0(전년도 펑크) → **'전년 펑크: 올해 몰림·반등 주의'**. 책 사례(건국대 경제학과 2311 펑크 → 2411 입결 상승, 경쟁률 4.0→6.2)와 같은 경우.
- t*=1~2(전전년 이전) 이고 t=0엔 없음 → **'변동성 있는 상향 후보'**.

### 4-4. 역할(학생 위치)에 따른 표시 (책 ④의 핵심)
앱 판정으로 역할을 나눕니다: **적정·예상 → 안정·적정 카드**, **소신·위험 → 상향·소신 카드**(책: 고속 진한·연한 녹색=안정 검토, 노랑·빨강=상향 검토).

| 역할 | 보여줄 칩 | 규칙 |
|---|---|---|
| 안정·적정 카드 | **안정적**(✓) | 변동성 안정 & 이벤트 없음 & R가 ±0.2 안 |
| | **변동 큼**(⚠) | 변동성 불안 또는 최근 3개년 이벤트 있음 |
| | **전년 입결 낮음 — 반등 주의**(⚠) | R ≥ +0.20 (책: 입결이 낮아 매력적인 안정 카드는 말린다) |
| | **전년 입결 높음 — 여유 가능** | R ≤ −0.20 (올해 하락 가능, 안정 쪽엔 유리) |
| 상향·소신 카드 | **펑크 후보**(1~3단계) | 하락 압력 점수 + 변동성 불안(+1) + 과거 이벤트(전전년 이전, +1) + 소수정원 보너스(정원 ≤5, 압력이 있을 때만 +1) |
| | **함정 — 전년 펑크**(⚠) | t*=0 또는 R ≥ +0.20 (올해 몰려서 입결이 오를 가능성, 상향 지양) |
| 공통 | 메모 | 수시이월(확정 전), 무전공·자율전공(계열 평균 수준, 마감 경쟁률 확인), 다군(상위 대학 합류 시 충원 많을 수 있음) |

표의 '펑크예측' 열은 이 칩 한 개(역할에 맞는 것)로 바꾸고, 정렬·필터에 "상향 카드 후보(펑크)"·"안정 카드 후보(변동 작음)"를 추가합니다. 근거 문장은 상세 패널(지금 구조 그대로: 근거 / 반대 근거·리스크 / 참고)에 넣습니다.

### 4-5. 상세 패널 화면(책의 눈으로 보는 방식)
5개년 합격권·70% 컷 꺾은선(두 선 사이 음영 = 충원 깊이), spike 해 노란 표시, 같은 대학·계열 중앙값 선, 이벤트 연도 마크. **유사학과 비교**: 표에서 학과 몇 개를 선택하면 5개년 합격권·70%컷과 순위 변화를 나란히 보여주는 화면(책의 건국대 정외·행정·사회·경제·경영 예시). 유사학과 묶음 기준(어떤 학과끼리 묶을지)은 컨설턴트가 고르게 하는 방식을 제안합니다.

| +0.20 ~ +0.30 | 175 | −0.108 | 8% | 48% |
| ≥ +0.30 | 199 | −0.258 | 7% | 75% |

- 후보로 뽑은 학과의 적중(다음 해 입결이 실제로 내려간 비율, 전체 기준선 20%):
  - **현재 로직**(r<0.78): 551개 후보, 적중 35%. 강한 후보(r<0.6): 52개, 63%.
  - **제안 로직**(R ≤ −0.20): 189개, 적중 **58%**. R ≤ −0.30: 77개, **69%**.
  → 후보 수는 1/3로 줄고 적중률은 크게 오릅니다.
- 변동성: 상위 30%(4개년 표준편차 ≥ 0.154) 학과는 다음 해 변화 폭이 0.242로 나머지(0.165)보다 큽니다. 낮음과 보통은 구분이 안 되어 **안정/보통은 한 단계로 합치는 것**이 맞습니다.
- 한계: 한 번의 해(2411→2511)만 되돌려 본 것이고 기준값도 같은 자료로 정했습니다. 도입 전에 연도를 바꿔가며 한 번 더 보는 것이 좋습니다(자료상 2411→2511 한 구간만 5개년이 모두 있는 단위가 많습니다).

## 6. 2차·3차 확장 (자료를 넣어야 하는 것)
### 2차 — 경쟁률 입력(책 ⑦⑧)
모집단위별 3개년 모집인원·최종 지원자 수(종로/대성/진학사/대학 공개자료)를 엑셀·CSV로 올리거나 상세 패널에 직접 입력 → 경쟁률 C.
```
ΔC = C_t − C_{t+1}   (±10% 이내는 '=')      ΔL = 상대 누백 변화(±0.10 이내는 '=')
패턴1 경쟁률↑ 입결↑ : 인기 학과, 입결 유지. 단 전년이 5개년 대비 과도하고 업체 고평가면 경쟁률↓ 충원↑ 펑크 가능
패턴2 경쟁률↓ 입결↓ : 함정. 소신 지원 폭발 → 입결 급등. 안정·소신 모두 지양
패턴3 경쟁률↑ 입결↓ : 비인기 학과 막판 몰림 → 5개년 평균으로 복귀(올해 입결 상승)
패턴4 경쟁률↑ 입결= : 평이, 적정·안정 카드로 적합
패턴5 경쟁률↓ 입결↑ : 강력한 펑크 후보(충원 적게 돌아 높은 성적만 등록)
```
접수 기간에는 '마감 직전 경쟁률'을 입력하면 예상 최종 경쟁률(= 직전 × 군별 배수, 책의 2025 기준 가 1.96·나 2.33·다 2.74)을 범위로 보여줍니다. 배수는 연도마다 달라 설정값으로 두고, 비인기 학과는 더 크게 오를 수 있다는 문구를 붙입니다.

### 3차 — 진학사 해석(책 ⑨, 컨설턴트용)
상세 패널에 입력 칸: 모의지원자 수 N, 내 등수 r, 모집인원 Q, 진학사 최초합격 예상 F, 추가합격 예상 A, 최근 3개년 적중률 a, 20장 모의지원자 수 W, 칸수.
```
합격자 내 위치 P = r / (F + A)                    // 예: 10 / (19+20) = 25.6%
지원 성향: ≤30% 하향 / 30~60% 안정 / 60~90% 적정 / 90~120% 소신 / 120~150% 상향 / ≥150% 우주상향   (100% 이상은 불합격 가능성 높음)
오차 범위 = P ± (1 − a) × 100%p                   // 예: a=92% → 25% → 17~33%
예상 지원자 수 = N × Q / F,  예상 실경쟁률 = N / F  // 예: 120×30/19=190명, 6.3:1
과대평가 의심 지표(4단계): ① Q/F가 클수록 ② W(20장 모의지원자)가 적을수록 ③ 예상 실경쟁률이 과거 3개년·비교 학과보다 높을수록 ④ 적중률이 낮을수록
                         + 앱의 입결 패턴이 '하락 예측'인데 진학사는 칸수를 짜게 줌 → 과대평가·펑크 가능성 ↑
진학사↔앱 판정 불일치: 칸수를 안정/적정/소신/상향으로 환산해 앱 판정과 2단계 이상 다르면 '결론이 갈림 → 펑크 가능성 ↑' 표시
```
표시 위치는 최종 지원 상세와 원서 전략 장(컨설턴트 내부용)이며, 보고서(학생용)에는 옮기지 않는 지금 원칙을 유지합니다.

## 7. 도입 순서(제안)
1. **1차(바로 가능, 새 자료 불필요)**: 4-1~4-4 (대학 흐름 보정, 70% 간극 교정, 이벤트·변동성, 역할별 칩) + 연도 표기 정리 + 필터. 분량 작음(`funkOf`·칩·필터), 위험 작음. 적용 전 5절 백테스트를 연도 바꿔 재확인.
2. **1.5차**: 상세 패널 스파크라인·유사학과 비교 화면.
3. **2차**: 경쟁률 입력(업로드/수동) → 패턴 판정 + 마감 직전 경쟁률 계산기.
4. **3차**: 진학사 값 입력 → 해석 도구.

## 8. 확인이 필요한 것·더 받고 싶은 자료
**결정이 필요한 것**
1. 표의 '펑크예측' 열을 **역할별 칩 한 개**로 바꿔도 되는지(안정 카드엔 '안정적/변동 큼/반등 주의', 상향 카드엔 '펑크 후보/함정').
2. 연도 표기: 분석기 머리글(2511…)대로 `2511(26학년도)`로 바꿀지, 아니면 책 표기에 맞춰 다른 방식으로 쓸지.
3. 경쟁률 자료를 어디서 구할 수 있는지(엑셀/CSV 가능 여부). 가능하면 2차를 진행.
4. 진학사 입력 도구(3차)를 앱에 넣을지, 책 내용으로만 둘지.

**책에서 더 받으면 좋은 부분**
- 앞 챕터 **"올해 입시의 거시적 변동"**(모집인원 증감·요강 변동·의대 증원·다군 신설) — 모집인원 증감과 요강 변화(반영비·가산점) 규칙을 점수에 넣을 수 있음
- 뒤 챕터 **"사람들의 심리, 대형 입시업체(진학사·고속) 경향성"** 과 **"실시간 경쟁률·표본 분석"**(마지막 챕터) — 3차·2차 입력값과 임계값의 근거
- **심화 스킬 챕터** 및 책에 나온 **임계값·숫자 표**(예: 지원 성향 구간, 칸수 해석, 충원율 기준)
- 컨설턴트가 쓰는 **유사학과 묶음 기준**이 있으면 그 목록(없으면 같은 대학·계열로 시작)
