## 1. 시점이 되면 반드시 다시 해야 하는 것
1. **12월 확정 정시모집요강으로 재검증** — 현재 근거는 8~9월 공개본이고 모든 요강에 "변경될 수 있음" 문구가 있다. 절차: `docs/DEC_RECHECK.md`, 바뀐 대학 골라내기: `tools/guide_diff.py` 【#1】
2. **수능 후 실제 성적이 반영된 고속성장분석기 파일 업로드** — 현재 데이터는 9월 모평 실채점판(date:20260928)이다. 수능 후 새 파일을 데이터 관리에서 업로드해 검증을 통과시키고, 판정·누백·합격권이 바뀌는지 확인한다. 이때 경희 한약학과·약과학과, 연세 첨단약과학과, 원광·우석 한약학과가 ★약대로 들어오지 않는지도 본다(약학에 포함하지 않는 것으로 확정) 【#2·#17】

4. **2028학년도 변경 예고(내년 업데이트 때 반영)** — 연세 학생부 정량 폐지·서류평가 신설, 경희 수능·학생부형 신설, 서강 정시 지역균형 신설 【#19】
5. **12월 요강에서 같이 확인** — 단국대 요강의 '2025학년도 이월인원 포함' 문구(연도 오기 의심, 천안 단위와 혼동 주의), 경북대 상주·강원대 등 요강이 '(안)'이거나 시행계획 기준이던 곳 【#1·#27·#29】

## 6. 화면·기능을 쓸 때 알아둘 점
- 전형 유형 표시는 분석기에 열이 없어 **모집단위 이름 표기**로 판별한다: [지역]=지역인재(서울대는 지역균형), [교과]=교과우수, [만학]=만학도, 군이 '수시이월'=수시이월, 끝 숫자 1·2=전형1·전형2(가천대는 일반전형1=백분위·2=등급이지만 가톨릭·수원·서경·한국공대 등은 의미를 확인하지 못함), 표기 없음='일반'. 농어촌·기회균형 등 정원 외 전형은 데이터에 없다. 지역인재 등의 지원 자격 문구는 메디컬 조사 JSON(`verify_med`)의 문장을 그대로 가져온 것이라 조사하지 않은 대학은 비어 있다 【#45】
- 환산 공식에 따라 학생 누백이 대표 누백과 크게 어긋나는 대학이 있다(예: 신한대는 상위 3개를 5:3.5:1.5로 합산하고 영어·한국사를 등급 환산해 상위 3% 학생이 상위 18%로 계산) 【#46】
- 보고서의 ~습니다체는 ~요체 문장을 규칙(`rpFormalize`)으로 바꾼 것이다. 새 대학 조사 내용이나 새 문구가 추가되면 보고서를 열어 어색한 어미가 없는지 확인 【#47】
- 대학 카드 아바타 글자는 대학명에서 '대학교/대학/대'와 괄호 표기를 뺀 이름이다. 같은 이름의 캠퍼스 분리 대학은 모집단위 중 가장 많은 지역의 색을 따른다 【#48】
- 정밀 매칭 필터의 칩 옆 숫자는 '그 칩을 단독으로 골랐을 때 남는 개수'다(여러 항목을 걸면 실제 결과 수는 더 적다). 필터 프리셋은 학생 데이터에 저장되므로 학생을 저장해야 보관된다('안정 위주'·'소신 도전'은 기본 제공). 표 체크박스 → '지원희망에 담기'는 이미 담긴 항목을 건너뛰고, 선택은 탭을 옮기면 초기화된다 【#49~#51】
- 학생 요약의 판정 분포는 **전문대 제외 + 과도한 하향 제외(기본 켜짐)** 기준이며 정밀 매칭 결과 수와 일치한다. 전국 등수·대표 누백은 '성적대 위치'의 추정값이지 실제 등수가 아니다. 추천 대학 TOP 5는 참고용이다. 정성 평가·내신 환산점수 섹션은 기본 접힘이고 값이 입력돼 있으면 자동으로 펼쳐진다. 저장 상태는 저장소(db) 연결 시에만 '저장됨 · 시각'이 뜬다 【#52~#56】
- 성적대 위치의 '위치' 칩(적정권/안정/상향)은 학생 누백 중앙값(◆)이 대학 적정 누백 25~75% 막대의 안/왼쪽/오른쪽 중 어디인지로 정한 표시이며 모집단위별 판정과는 별개다. '학생 근처 대학만'은 대학 적정 누백 중앙값이 학생 대표 누백의 0.35배 이상 1.6배 미만인 대학만 보여주므로(기본 꺼짐) 하향 지원을 볼 때는 꺼 둘 것. 학생 성적 표에서 영어·한국사는 등급만 표시하고, 탐구 2가 탐구 1과 같은 과목이면 표에 나오지 않는다 【#57~#59】
